# 按模型结构选择最小有效工作

先读取原模型和本组有效产物，不从文件名推断算子；无需用户提供RF/精度/历史实现。
这是实现建议，不能取代ORDER的256完整板输出原Python标准，不能裁剪Sigmoid/Softmax。

| 实际结构/前端 | 先读的证据 | 避免的重复工作 | 支持边界 |
|---|---|---|---|
| 单输出Dense+Sigmoid | 实际权重/累加/激活类型、CPU逐值误差、既有路径报告 | 仅因打包器/可选时序报告失败而重新部署；无依据扩大全部类型 | 非线性保留，物理策略修改可保留适用综合结果 |
| 多层Dense | 各层实际RF及有效LayerName覆盖、原权重网格、首次可映射层偏差 | 合法局部RF被错报为global不一致后重建；每层重复跑整段CPU图 | RF建议不等于资源/延迟；局部主机搜索只支持普通Keras规定接口 |
| Dense+完整Softmax | 实际exp/inv/accum类型、表规模与调度，CPU误差 | CPU已满足容差后继续为了误差更小而扩大表和位宽；默认cosim循环 | 稳定/延迟/legacy算法使用角色不同，按实际生成实现 |
| QKeras量化图 | 原量化器、导出量化权重、输入激活边界及完整非线性 | 统一扩内部类型或去掉原量化器；缺一个参考JSON就从头重建 | opt3支持QKeras JSON权重、io_parallel单输入输出主机诊断；拒绝weight/bias/result覆盖，不替代板测 |
| ONNX分支/Concat/多拍输出 | 原分支拓扑、生成整样本输出extent/lane/拍数、真实完整输出 | 改接口时丢弃有效算术核心；误把接口限制当成模型不支持 | 原模型有多少输出就保留多少；不补Softmax，不裁成单拍。不支持的ABI必须具名诊断，禁止凑答案 |
| Conv1D/Conv2D | 卷积乘法config、空间几何、有效kernel、已有层级映射 | 只看RF数字就反复重综合；用Conv1D宽度公式替代二维kernel | Conv2D含height；缺字段unknown。聚合资源不能定位层级原因 |

## 通用顺序

1. 检查本组已有实际结果和变更范围，保留原模型/输入/权重及失败记录。
2. CPU误差未满足时先定位，不默认启动完整RTL/cosim/实现。CPU通过只是开发证据，仍须真实部署。
3. 静态读取生成的有效配置和kernel，再按已有报告提出一个可验证假设；不要为完善表格加一次EDA。
4. 只变更受影响阶段。有效核心/综合checkpoint的复用需完整依赖身份和实际有效性证据，不能从bit存在推断。
5. 完整256真实板输出数值通过即停止部署；打包、资源/时序、HLS双参考均不触发额外重跑。

## 工具的具体收益和未知

RF咨询解析显式LayerName和layer_reuse_factors；LayerType身份未由生成记录确定时请求RF保留null，不能报成错误global覆盖。
Keras层参考对无状态普通图一次请求所有可映射层输出；fused输出的旧边界限制不变，stateful图保留旧逐层行为。
这是主机诊断计算减少，不是硬件延迟改善；不扩展local_precision_search的前端/io_parallel支持边界。
任何不支持的工具路径，应使用已有原前端的最小合法流程，而不是去掉量化、合并分支或替换模型。
